# Manuscript Builder

A free browser-based editor for creating immersive TTRPG handouts: letters,
decrees, grimoires, dossiers, science-fiction datapads, and other in-world
documents.

Manuscript Builder is part of **Bag Of Holding Tools**. The current first slice
establishes the shared application shell, multi-page editor, four visual style
families, live content editing, zoom controls, and print/PDF export.

## Development

```bash
pnpm install
pnpm dev
```

Open <http://localhost:3000>.

```bash
pnpm build
pnpm lint
```
